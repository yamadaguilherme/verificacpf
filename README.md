# Validador de CPF em Python🤖

Este é um script em Python que valida a autenticidade de um número de CPF brasileiro. O projeto foi desenvolvido como um exercício prático para aplicar conceitos fundamentais da linguagem.

## Funcionalidades
- Valida CPFs com 11 dígitos, com ou sem pontuação (ex: 12345678901 ou 123.456.789-01).

## Tecnologias Utilizadas
- Python 3
- Funções, listas, compreensão de listas (list comprehension) e generator expressions.

## Como Executar
1. Certifique-se de ter o Python 3 instalado.
2. Clone este repositório.
3. Execute o arquivo `verificador_cpf.py` no terminal:
   `python verificador_cpf.py`
